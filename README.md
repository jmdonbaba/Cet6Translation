# CET-6 翻译助手

> 不只是"看答案"，而是一个让你**在批改中成长**的六级翻译深度学习工具。

[![License](https://img.shields.io/badge/license-MIT-blue.svg)](LICENSE)
[![DeepSeek](https://img.shields.io/badge/AI-DeepSeek%20Chat-4f46e5.svg)](https://www.deepseek.com/)

---

## 核心理念

翻译能力不是"看"出来的，是"练"出来的。这个工具的设计围绕一个闭环：

**出题 → 自己翻译 → AI 四维深度批改 → 针对性改进 → 再练下一题**

你不会看到"标准答案"就被动结束——你会看到你在语法、词汇、句式每个维度上的具体问题，以及怎么改。

---

## 功能

### 📝 AI 智能出题
- DeepSeek 实时生成 CET-6 难度的中文翻译题（150-200 字）
- 覆盖文化、经济、科技、社会、教育等真题话题
- 支持手动输入自定义题目
- 点击「换一题」刷新

### 💡 提示搜索
- 与题目并排显示，输入题目中的词、句子或翻译问题
- AI 给出方向性引导：可用词汇、句型思路、翻译策略
- **不会直接给完整答案**——引导你独立思考，实在想不出再点「直接看答案」

### ✏️ 自己动手翻译
- 大文本输入框，自由输入英文译文
- 实时字数统计
- 「直接看答案」随时查看参考译文

### 📊 AI 四维深度批改

提交后 AI 从四个维度逐条分析，分 Tab 展示：

| 维度 | 内容 |
|------|------|
| **语法纠错** | 逐句扫描语法错误，指出错误原文 → 正确写法 → 详细解释 |
| **词汇升级** | 标记可替换的词 → 推荐更高级/地道的表达 → 说明替换原因 |
| **句式优化** | 指出中式英语/不自然的句式 → 给出改写建议和英文句式框架 |
| **逐句对比** | 表格形式，你的翻译 vs 参考译文逐句对照 + 点评 |

每个 Tab 带计数角标，一目了然。顶部有总分评分（0-100）和总体评价。

### 🔍 智能查词
- 输入任意英文单词，秒得音标、释义、变形、3 个作文级例句
- **自动识别变形**：搜 `automating` → 提示是 `automate` 的现在分词
- 多面板支持（+/- 按钮），同时查多个词
- 例句含六级高级词汇，本身就是学习材料
- 一键收藏到共享词汇本

### ⭐ 双收藏系统
- **词汇收藏**：与 Cet6Dictionary / Cet6Writing 共享 `cet6_vocab_favorites` key，一处收藏三处查看
- **翻译收藏**：保存题目 + 你的译文 + 参考译文 + 完整批改结果
- 均支持置顶/取消置顶/删除
- 数据保存于浏览器 localStorage

## 快速开始

### 1. 获取 API Key

前往 [DeepSeek 开放平台](https://platform.deepseek.com/) 注册并获取 API Key。

### 2. 打开应用

- **在线使用**：https://jmdonbaba.github.io/Cet6Translation/
- **本地使用**：双击 `index.html`，输入 DeepSeek API Key（以 `sk-` 开头），点击保存。

### 3. 开始练习

- 页面自动生成一道翻译题
- 在输入框输入你的英文译文
- 点击「提交批改」查看四维分析
- 遇到不确定的地方用右侧「提示搜索」查询
- 不认识的词用底部查词模块

> 💡 无需安装任何依赖，无需服务器，纯前端运行。

## 设计原则

- **零依赖**：不引入任何第三方库或框架，降低维护成本
- **共享生态**：与 Cet6Dictionary、Cet6Writing 共享词汇收藏和 API Key
- **离线友好**：已生成的内容可离线查看，数据本地持久化
- **移动适配**：响应式布局，手机端同样可用
